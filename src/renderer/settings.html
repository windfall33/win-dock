Dock 设置

图标大小
放大倍率
自动隐藏
鼠标移开时 Dock 滑出屏幕
Dock 常驻（恒浮）
开启后前台有应用窗口也不自动收起（macOS 默认恒浮）；关闭则智能收起，把屏幕让给应用
每屏一条 Dock
每块显示器各放一条（macOS「Displays have separate Spaces」）；关闭则跟随鼠标单条
运行指示点
运行中的应用图标下方显示小圆点（macOS 设置项）
最近应用区
分隔线右侧显示最近打开的应用（macOS「Show suggested and recent apps」）
只显示运行中
隐藏全部固定项，Dock 变纯运行区（macOS static-only）
滚轮悬停切换窗口
在图标上滚动 = Exposé / 展开堆栈（macOS scroll-to-open，默认关）
拖文件悬停打开应用
拖文件悬停在应用图标上自动打开（macOS spring-load，默认关）
唤回延迟
贴边后多久唤出 Dock（macOS 默认约 200ms）
收起延迟
指针离开后多久收起
外观
Dock 位置
底部 / 左侧 / 右侧，与 macOS 一致
最小化效果
genie 吸入 / scale 缩放，与 macOS 一致
最小化到应用图标
最小化窗口收进对应应用图标，不放右侧分区（macOS 设置项）
开机自动启动
登录 Windows 后自动运行 Dock
顶部菜单栏
屏幕顶部的应用名与时钟；关闭可省约 50MB 内存
隐藏 Windows 任务栏
一键自动隐藏任务栏，仅保留 Dock；关闭可还原
全屏应用时让位
仅当真全屏应用时自动让位，鼠标贴边可唤回；普通窗口（含最大化）不触发遮挡隐藏。关闭则全屏时也保持显示
多显示器跟随
在多个屏幕间移动鼠标时，Dock 跟着出现在当前屏幕
工作区预留
最大化窗口自动避开 Dock（macOS 行为）。仅对主显示器生效；Dock 隐藏任务栏时无需开启
提示：右键点击 Dock 图标可固定/移除应用、关闭程序；
中键点击运行中的应用图标可打开 Exposé 窗口缩略图（Esc 或点击空白关闭）；
把 .exe 或快捷方式拖到 Dock 上即可固定应用；
把文件拖到应用图标上用该应用打开，拖到底部废纸篓即删除到回收站。
快捷键：Ctrl+Shift+D 切换自动隐藏，Ctrl+Shift+M 切换放大，Ctrl+Shift+P 切换位置。
进阶：config.json 可调 showDelayMs / hideDelayMs（贴边唤回与收起延迟，macOS autohide 节奏位语义）。
为获得最纯粹的体验，建议将 Windows 任务栏设置为「自动隐藏任务栏」。

最小化窗口收进对应应用图标，不放右侧分区（macOS 设置项）

登录 Windows 后自动运行 Dock
顶部菜单栏
屏幕顶部的应用名与时钟；关闭可省约 50MB 内存
隐藏 Windows 任务栏
一键自动隐藏任务栏，仅保留 Dock；关闭可还原
全屏应用时让位
Dock 恒浮于普通窗口之上（含最大化/铺满不会让 Dock 隐藏）；仅当全屏应用时才自动收起，鼠标贴边可唤回。关闭则全屏时也保持显示
多显示器跟随
在多个屏幕间移动鼠标时，Dock 跟着出现在当前屏幕
工作区预留
最大化窗口自动避开 Dock（macOS 行为）。仅对主显示器生效；Dock 隐藏任务栏时无需开启
提示：右键点击 Dock 图标可固定/移除应用、关闭程序；
中键点击运行中的应用图标可打开 Exposé 窗口缩略图（Esc 或点击空白关闭）；
把 .exe 或快捷方式拖到 Dock 上即可固定应用；
把文件拖到应用图标上用该应用打开，拖到底部废纸篓即删除到回收站。
快捷键：Ctrl+Shift+D 切换自动隐藏，Ctrl+Shift+M 切换放大，Ctrl+Shift+P 切换位置。
为获得最纯粹的体验，建议将 Windows 任务栏设置为「自动隐藏任务栏」。
